# Vkusnyakhi-back
бек для сайта с вкусняшками
## Запуск 
1. Создание нового виртуального окружения:\
```python3 -m venv venv ```\
```source venv/bin/activate```
2. Установка зависимостей:\
```pip install Flask```\
```pip install psycopg2```\
``` pip install dotenv```
3. Запуск:\
```python3 app.py```
## Конфигурация

| Название             | Описание                                                    |
| -------------------- | ----------------------------------------------------------- |
| `host`               | Переменная для хоста                                        |
| `database`           | Переменная для названия бд                                  |
| `user`               | Переменная для имени пользователя                           |
| `password`           | Переменная для пароля                                       |
## Ручки (endpoints)

### `/food`
Ручка для получания еды
### `/drinks`
Ручка для полуения напитоков
### `/categories`
Ручка для получения категорий, имеет query парамерт type=(drinks или food)
### `/newProduct`
Ручка для создания нового товара
